PROJECT SPECIFICATION // COLLISION DETECTOR

PROJECT NAME: ESP32 Ultrasonic Collision Detector & Telemetry Engine
TARGET HARDWARE: ESP32 Microcontroller, HC-SR04, Passive Buzzer, LED
PRIMARY STACK: C++20 / FreeRTOS / Node.js / HTML5 WebSockets / SQLite

1. System Architecture & Objectives

An embedded telemetry system using an ESP32 microcontroller and HC-SR04 ultrasonic sensor to calculate real-time proximity and target velocity. The hardware interface provides physical auditory/visual alert cues while concurrently streaming JSON telemetry frames via WebSockets to a web dashboard and SQLite persistence engine.

2. Hardware & Firmware Requirements

  • Voltage Step-Down: Resistor divider (5V to 3.3V) on HC-SR04 ECHO signal pin.
  • Pulse Timing: Hardware-level GPIO interrupts attached to ECHO transitions.
  • Signal Filtering: C++ Exponential Moving Average (EMA) to suppress sonar jitter.
  • Alert Logic: Non-blocking hardware PWM (LEDC) tone control for passive buzzer.
  • Concurrency: Core 1 pinned to high-frequency acquisition; Core 0 pinned to network telemetry.

3. Execution Roadmap

Phase Focus Area Technical Output
01 Hardware Driver Interrupt-driven HC-SR04 measurement & LEDC PWM buzzer module.
